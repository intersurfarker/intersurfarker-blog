## 概述

本目录整理统计数据分析的学习笔记，内容从概率论与常用分布出发，逐步进入蒙特卡罗方法、统计检验、参数估计与置信区间，并进一步讨论特征函数和解谱等分析工具。笔记以物理实验数据分析为主要背景，关注如何从带有统计涨落、测量误差和探测器效应的数据中进行推断。

目前正文共 11 章，另有一篇从逻辑基础出发讨论概率论的《概率论沉思录》。

## 笔记列表

### 概率论基础

- **[基本概念](r9r806xh/)**：概率论的基础知识，包括概率公理、随机变量、条件概率、贝叶斯定理、概率密度函数、期望值、方差、协方差、误差传递和随机函数的正交变换等核心概念。
- **[常用概率函数](0n9zym1x/)**：详细介绍常用的概率分布，包括二项分布、多项分布、泊松分布、均匀分布、指数分布、高斯分布（含多维推广及中心极限定理）、对数正态分布、卡方分布和柯西（布莱特-魏格纳）分布等，涵盖其定义、性质和应用场景。

### 随机模拟与统计检验

- **[蒙特卡罗方法](5266ww2h/)**：介绍蒙特卡罗积分的基本思想与收敛特性、逆变换采样和舍选法等随机数生成方法，以及事例产生、探测效率统计和重要性抽样等方差缩减技术。
- **[统计检验](hcymahsn/)**：涵盖原假设与备择假设、检验统计量、显著性水平和检验功效，讨论 Neyman–Pearson 引理、似然比、费舍尔甄别函数、拟合优度检验、皮尔逊卡方检验和观测信号显著性。

### 参数估计

- **[参数估计的一般概念](c9udqr5i/)**：介绍样本、估计量、偏倚、相合性和均方差等概念，并推导均值、方差和协方差的常用估计量及其统计不确定度。
- **[极大似然法](3ht716io/)**：阐述极大似然估计量及其方差，涵盖解析法、蒙特卡罗法、Rao–Cramér–Fréchet 边界和图解法，并讨论扩展似然、分区间数据拟合、拟合优度和实验测量合并。
- **[最小二乘法](jd17y8ls/)**：从极大似然法说明最小二乘拟合的基础，讨论线性拟合、协方差矩阵、分区间数据、拟合优度，以及相关测量结果的合并。
- **[矩方法](ph9i5vu7/)**：通过令样本矩与理论期望相等来估计参数，比较其与极大似然法的效率，并给出估计量协方差矩阵的计算方法。
- **[统计不确定度、置信区间和极限](574gr2jf/)**：从估计量的抽样分布出发，系统介绍标准差、Neyman 置信区间、高斯与泊松区间、Fisher 变换、似然或卡方区间、多参数置信区域，以及存在物理边界或本底时的上限构造。

### 分布分析与逆问题

- **[特征函数](./10.%20特征函数.md)**：介绍特征函数与概率密度的傅里叶变换关系，以及利用特征函数计算矩、处理独立随机变量之和、研究分布的参数极限和证明中心极限定理的方法；最后用它推导估计量的概率分布。
- **[解谱法](./11.%20解谱法.md)**：从分辨率、探测效率和本底建立响应矩阵模型，讨论直接反演与修正因子法的局限，并系统介绍 Tikhonov、熵和交叉熵正则化，以及估计量方差、偏差和正则化参数的选择。

### 概率论的逻辑基础

- **[概率论沉思录](qkeu90ko/)**：探讨概率论的逻辑基础，包括布尔代数、完备集、合情推理（Plausible Reasoning）、乘法规则和加法规则等，从哲学和逻辑角度理解概率论的基本原理。

## 学习路径建议

1. 从**基本概念**和**常用概率函数**开始，建立随机变量、期望、方差和典型分布的基础。
2. 学习**蒙特卡罗方法**，理解如何通过随机抽样完成数值积分、模拟实验过程并降低估计方差。
3. 学习**统计检验**，掌握假设检验、似然比、显著性与拟合优度的基本框架。
4. 按照“**参数估计的一般概念 → 极大似然法 → 最小二乘法 → 矩方法**”的顺序学习点估计，并比较不同估计量的偏差、方差和适用条件。
5. 学习**统计不确定度、置信区间和极限**，将点估计扩展为可报告的误差、区间和上限。
6. 学习**特征函数**，把概率分布、独立变量求和、中心极限定理和估计量抽样分布联系起来。
7. 最后学习**解谱法**，综合运用响应矩阵、极大似然、最小二乘、协方差和偏差—方差权衡来处理带探测器效应的逆问题。

《**概率论沉思录**》可以作为独立的理论支线阅读，用于理解概率规则背后的逻辑基础。
